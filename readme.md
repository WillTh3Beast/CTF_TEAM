# Getting Started 

This document contains a list of resources worth looking into if you want to learn hacking. 

# MAIN RESOURCES
## Environment Setup

You will need a Linux VM for practice. 

For simplicity you can just install VirtualBox and download an iso for either Kali or ParrotOS. 

Kali is a Linux distro by OffSec which comes with a bunch of hacking tools very popular among pentesters. 

ParrotOS is a Linux distro by HackTheBox and is similar to Kali, but configured slightly differently. 

- Linux VM
	- Virtual Box: https://www.virtualbox.org/wiki/Downloads
	- Kali Linux: https://www.kali.org/get-kali/#kali-platforms
	- ParrotOS: https://parrotsec.org/
